# 課題0501 範囲判定と境界値

入力された int 整数が **0 以上 10 未満** のとき「OK」，そうでないとき「NG」と表示するプログラム `main.c` を完成させよ．

ヒント: 変数を x として，条件式は「 0 <= x < 10 」とは書けない．
「0<=x」という条件式と「x<10」という条件式を `&&` で組み合わせる．

## もう1つの課題: 境界値テストを書く
プログラムのバグは **境界** (条件が変わる所) に出やすい．`tests.txt` に，**入力と期待する出力** を1行ずつ書け．

```
入力 期待出力
```

少なくとも **-1, 0, 9, 10** の4つを含めること(境界の内側と外側)．期待出力は，このプログラムが **正しく動いたとき** の表示である．

## 提出するファイル
- `main.c` : プログラム
- `tests.txt` : 自分で考えた境界値テスト
- `ai_log.txt` : AI利用ログ
